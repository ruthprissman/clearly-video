# מצב הכנה: המחשב מוכן לווידאו

המטרה: בסוף המצב הזה יש סרטון בדיקה של 5 שניות בעברית שנוצר במחשב שלך. אם הוא
יצא, הכול עובד.

## איך אני מתנהג כאן
- כל מה שאני מתקין כאן חינמי ובטוח: כלים מוכרים בקוד פתוח, מהמקורות הרשמיים שלהם.
- קודם בודק, אחר כך מתקין. לא מתקין שום דבר שכבר קיים.
- לפני כל התקנה כותב משפט אחד: מה זה ולמה צריך. ומבקש אישור.
- אחרי כל התקנה בודק שוב. ב-Windows צריך לפעמים לסגור ולפתוח את הטרמינל,
  או את קלוד קוד, כדי שהמחשב "יראה" תוכנה חדשה. אם זה המצב, אני אומר לך
  בדיוק מה ללחוץ ואיפה נמשיך.
- בסוף: טבלה של מה נבדק, מה הותקן ומה נשאר.

## 1. בדיקה
מריץ ובודק גרסאות:

| מה | פקודת בדיקה | צריך |
|---|---|---|
| Node.js | `node -v` | 22 ומעלה (HyperFrames דורש 22+) |
| FFmpeg | `ffmpeg -version` | כל גרסה עדכנית |
| Git (רק ב-Windows) | `git --version` | מומלץ. בלעדיו קלוד קוד משתמש ב-PowerShell |

## 2. התקנה של מה שחסר

**Windows** (דרך winget, שמגיע עם Windows 10/11):
```
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Gyan.FFmpeg -e
winget install --id Git.Git -e
```
**Mac** (דרך Homebrew. אם אין Homebrew, קודם מסביר ומתקין אותו מ-brew.sh):
```
brew install node ffmpeg
```
אחרי ההתקנה: בודק שוב את הטבלה. ב-Windows, אם הפקודה עדיין לא נמצאת, מבקש
לסגור ולפתוח את קלוד קוד וממשיך מהשלב הזה.

**רשת מסוננת (נטפרי וכדומה):** אם הורדות נכשלות עם שגיאת תעודה (certificate),
עוצר ומסביר: צריך להגדיר את תעודת הסינון ל-Node ול-npm לפי ההוראות
של ספקית הסינון. לא מנסה לעקוף את הסינון.

## 3. הסקילים של HyperFrames
```
npx skills add heygen-com/hyperframes --skill '*' -g -a claude-code -y
```
זה מתקין את הסקילים בתיקיית הסקילים שלך (`~/.claude/skills`). אחר כך אומר לך
לפתוח מחדש את קלוד קוד כדי שיופיעו, וממשיכים.

**רשות, למי שרוצה גם את Remotion** (מנוע וידאו אחר, ב-React):
```
npx skills add remotion-dev/skills -g -a claude-code -y
```
שימי לב: Remotion חינמי לאנשים פרטיים ולחברות קטנות, ולחברות גדולות יותר יש רישיון
בתשלום. אני ממליץ להתחיל עם HyperFrames, שהוא קוד פתוח בלי הגבלה.

## 4. התיקייה
יוצר את `הסרטונים שלי` (או שם שתבחרי) עם התת־תיקיות מ-SKILL.md, ומעתיק את
`assets/brand-template.md` ל-`brand.md`.

## 5. סרטון בדיקה
עם `/hyperframes`: סרטון של 5 שניות, 1080×1920, רקע בצבע אחד, וכותרת בעברית
שנכנסת בתנועה: "זה עובד! הסרטון הראשון שלי". מרנדר ל-`out/בדיקה.mp4`, ומחלץ
פריים מהשנייה 3 כדי לוודא שהעברית מימין לשמאל ולא הפוכה. מראה לך את הפריים.

## תקלות נפוצות
- `claude` או `node` "is not recognized": המחשב עוד לא רואה את ההתקנה. סוגרים ופותחים
  את הטרמינל. אם זה לא עוזר, מפעילים מחדש את המחשב.
- winget לא קיים: ב-Windows 10 ישן מתקינים את "App Installer" מ-Microsoft Store.
- הרינדור נתקע: בודק שאין תהליכי Chrome תקועים שהרינדור פתח, ומריץ שוב עם
  פחות עובדים במקביל.
